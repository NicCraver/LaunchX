## Why

LaunchX 在简约模式下进入扩展界面（如 Zed 的最近打开项目）时，扩展内容被错误地挤压到简约模式的输入框中，而不是正确展开显示。这导致用户无法正常使用扩展功能，影响核心用户体验。

## What Changes

- 修复简约模式下扩展界面的布局逻辑，确保扩展内容正确展开而不是被挤压到输入框中
- 调整简约模式和全屏模式切换时的视图层级和约束处理
- 确保扩展界面在两种模式下都能正确显示

## Capabilities

### New Capabilities

无新增功能

### Modified Capabilities

- `shared-ui-components`: 修复简约模式下扩展界面的布局行为，确保扩展内容正确展开显示

## Impact

**受影响的组件：**
- 简约模式的视图控制器和布局逻辑
- 扩展界面的容器视图和约束系统
- 模式切换相关的视图管理代码

**回滚计划：**
- 通过 git revert 恢复到修复前的版本
- 布局修复为纯视图层改动，不涉及数据层，回滚风险低

**测试范围：**
- 简约模式下打开各类扩展（Zed、VSCode 等）
- 全屏模式下打开扩展验证无回归
- 简约模式和全屏模式之间切换时的扩展显示
